Car Parking System - Architecture Specs

Distributed Microservices Architecture

Key Microservices Components:

Slot Allocation Service Maintains state of empty/reserved spots with atomic Redis locks.
Tariff & Billing Service Dynamic pricing formulas based on vehicle type and duration.
Access Gate Controller Sensor-event webhooks for entry/exit timestamp validation.
Docker Containerization Docker compose orchestrated setup with isolated networks.

Resilience & Concurrency:

Handles race conditions when multiple vehicles arrive at peak hours by utilizing distributed key locking in Redis. Database transactions adhere to ACID constraints via Spring Data JPA with optimistic locking mechanisms.
